API Contract — Capstone Project

Dokumentasi endpoint backend (Express) berdasarkan implementasi di folder server/ (router: server/src/routes, validator: server/src/validator, middleware auth/role, dan helper response).

Base URL & Konvensi

Base API
http://localhost:5000/api (default: PORT env, fallback 5000 di server/server.js)
Mounting
Semua endpoint ini dimount dari server/server.js ke /api/. Router yang tersedia (lihat server/src/routes/index.js):
  • /api/auth
  • /api/profile
  • /api/umkm
  • /api/product
  • /api/transaction
  • /api/chatKonsul
Auth (cookie)
Backend menggunakan httpOnly cookies (bukan header Bearer). Middleware auth membaca token dari req.cookies.accessToken.
  • accessToken (JWT, ~15 menit)
  • refreshToken (~7 hari)
Client wajib mengirim cookie:
  • fetch: credentials: 'include'
  • axios: withCredentials: true
Catatan: cookie saat login diset dengan secure: true dan sameSite: 'none'.
Format sukses
{
  "status": "success",
  "message": "...",
  "data": {}
}
Format gagal (helper)
{
  "status": "failed",
  "message": "..."
}
Gagal validasi (Joi)
{
  "status": "failed",
  "message": "Validasi Gagal",
  "errors": {
    "field": "pesan error"
  }
}
404 (global)
{
  "status": "failed",
  "message": "Halaman yang kamu cari tidak ditemukan"
}
500 (server)
{
  "status": "Error",
  "message": "Terjadi kesalahan di server"
}
Static uploads
Server mengekspose server/public/uploads via /uploads:
  • http://localhost:5000/uploads
Namun upload foto UMKM/Profile saat ini memakai Cloudinary via server/src/middleware/claudUpload.js, sehingga photo_url biasanya berupa URL Cloudinary.

Uploads (Static)

Server mengekspose static folder server/public/uploads melalui path /uploads.

GET /uploads/<path>

AuthTidak perlu
ResponseBinary file (image)
Contohhttp://localhost:5000/uploads/profiles/any.png
Catatan: endpoint Profile/UMKM upload saat ini memakai Cloudinary; section ini hanya untuk file yang memang ada di server/public/uploads.

Catatan

  • Endpoint yang tidak butuh cookie accessToken: /auth/register, /auth/login, /auth/refresh-token.
  • Endpoint /auth/users* membutuhkan role admin (role dicek dari payload JWT di cookie).
  • Upload foto (UMKM/Profile) memakai Cloudinary via multer-storage-cloudinary. Field file harus bernama photo.
  • Transaksi menggunakan amount (number) dan type bernilai income / expense sesuai validator.
