API Contract — Capstone Project

Dokumentasi endpoint backend (Express) berdasarkan folder server/src/routes, validator (Joi), helper response, dan middleware yang ada.

Base URL & Konvensi

Base API
http://localhost:3000/api (default; mengikuti PORT di server/server.js)
Static uploads
http://localhost:3000/uploads (folder fisik: server/public/uploads)
Auth (backend)
Backend menggunakan httpOnly cookies:
  • accessToken (15 menit)
  • refreshToken (7 hari)
Untuk client (fetch/axios) wajib mengaktifkan cookie:
  • fetch: credentials: 'include'
  • axios: withCredentials: true
Format sukses

  "message": "...",
  "data": { }
}
Format gagal (umum)
{
  "status": "failed",

}
Format gagal validasi (Joi)
{
  "status": "failed",
  "message": "Validasi Gagal",
  "errors": {
    "field": "pesan error"
  }
}
Format error server (500)
{

PUT /profile

AuthWajib cookie accessToken (httpOnly)
Content-Type Disarankan multipart/form-data jika mengirim file. Tanpa file bisa juga application/json.
Body fields (validator)
  • gender (string, required, salah satu: Laki-Laki | Perempuan)
  • phone_number (string, required; boleh kosong ""; min 10 max 15)
  • address (string, required; boleh kosong "")
  • date_of_birth (date, required; harus < sekarang; format input yang umum: YYYY-MM-DD)
  • photo (file, optional; field name harus photo)
Upload rules
  • Mime type diterima: image/jpeg, image/jpg, image/png
  • Maks ukuran file: 2MB
  • Disimpan ke: server/public/uploads/profiles
  • URL yang disimpan: /uploads/profiles/<filename>
Response 200 (contoh, update/create) 
{
  "status": "success",
  "message": "Profil berhasil diperbarui",

Contohhttp://localhost:3000/uploads/profiles/1710000000000-123.png

Catatan Penting

  • Semua endpoint selain /auth/* membutuhkan cookie accessToken (httpOnly). Client harus mengirim cookie dengan credentials: 'include'.
  • Jika terjadi error validasi, response mengikuti format message: "Validasi Gagal" dengan errors per field.
  • Beberapa endpoint delete/logout mengembalikan data bertipe string (sesuai pemanggilan helper success()).
  • Nama field transaksi memang amout (bukan amount) sesuai validator dan route.
